# BC-11 — Business Traceability

Responsable frontend: ownership documental de la frontera reservada para Buyer Portal.

Este contexto canónico no tiene contrato ni proyección frontend implementada en Portal. Sus cuatro capas están documentadas para conservar la frontera, sin agregar endpoints, entidades, dependencias, rutas ni comportamiento especulativo.

La definición autoritativa vive en [Blueprint BC-11](https://github.com/nexa-suite/blueprint/tree/main/01-shared/domain/bounded-contexts/BC-11-business-traceability).

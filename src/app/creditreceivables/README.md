# BC-07 — Credit & Receivables

Responsable frontend: proyección autorizada de cuentas por cobrar.

La raíz contiene las cuatro capas directas. La página visible de cuentas por cobrar vive en la composición explícita `core/compositions/receivables-payment`, que combina BC-07 y BC-08; este BC no inventa una fachada o una ruta propia adicional.

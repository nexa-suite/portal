# BC-04 — Sales Commitment

Responsable frontend: solicitudes de compra, pedidos y órdenes de venta buyer.

La raíz contiene las cuatro capas directas. Sus subdominios `buyer-requests`, `purchase-requests` y `orders` se organizan dentro de cada capa, no como una carpeta envolvente del BC. Las integraciones con BC-02, BC-03 y BC-06 son gateways/ACL explícitos en `infrastructure`.

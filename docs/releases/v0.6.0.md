# Nexa Buyer Portal v0.6.0

## Historical version mapping

Former historical label: `v0.7.0`. Public version: `v0.6.0`. Target commit,
original chronology and release evidence were preserved during the
Owner-authorized SCM normalization on 2026-09-01.

## Summary

Consolidated TASK-NEXA-008, TASK-NEXA-008.6, TASK-NEXA-009, TASK-NEXA-010 and TASK-NEXA-010.5 into the Buyer commercial and delivery-tracking surface.

## Highlights

- Workspace recognition, localized catalog, Purchase Request and Sales Order buyer flows.
- Buyer-safe My Deliveries and Delivery Detail with status timeline and POD metadata.
- Client-account-scoped delivery mapping with internal identifiers excluded from rendered views.
- Responsive buyer shell with explicit loading, empty, error and retry states.

## Validation

- `npm test`: 28 test files and 44 tests passed.
- `npm run build`: production build passed without budget warnings.
- `npm audit --omit=dev`: 0 vulnerabilities.
- Canonical Modern Docker source build and authenticated responsive browser checks passed.

## Boundary

POD evidence is metadata-only. Evidence-file storage, business documents, invoices, payments and production deployment remain outside this release.

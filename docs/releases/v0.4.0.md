# Nexa Buyer Portal v0.4.0

## Summary

Buyer-only access and secured Product Catalog discovery release.

## Highlights

- Added Buyer sign-in with identifier, password and workspace slug.
- Added session restoration, in-memory access-token handling and Buyer surface enforcement.
- Added protected `/portal/home`, `/portal/product-catalog` and detail routes with aliases.
- Added responsive buyer catalog grid, search, filters, pagination, detail reload and retry states.

## Security impact

Portal accepts `BUYER` only; internal memberships are rejected. Tokens are not stored in browser storage. API remains final authorization authority.

## Breaking changes

Old shell-only route behavior is replaced by authentication-gated Buyer routes. `/home`, `/portal/catalog` and detail aliases remain supported.

## Migration impact

Configure API runtime URL and local credentials through existing runtime configuration. No package migration included.

## Validation

Unit tests, Angular build, catalog asset validation and browser scenarios are required before publication; exact results belong to final audit evidence.

## Known limitations

No full visual parity with Vue, complete Nexa migration or production deployment is claimed. No cart, stock claim, promotion, discount or buyer-specific pricing is included.

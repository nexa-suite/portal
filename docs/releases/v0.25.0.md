# Portal v0.25.0

Date: 2026-08-29

## Summary

API-only Buyer Purchase Request summaries with server-owned line counts.

## Included

- Purchase Request list cards render `lineCount` from the existing
  `GET /api/v1/purchase-requests` summary contract.
- Product line details render only when the response includes `lines`; the
  Portal no longer fabricates product identity from a summary response.
- Browser runtime configuration ignores mock switches and keeps existing HTTP
  adapters selected for Buyer routes.
- Focused component, client, facade, provider and runtime tests cover the
  change.

## Architecture and boundary

- Existing `PurchaseRequestApiClient`, application ports and server contracts
  remain authoritative.
- No new endpoint, entity, state, persistence model, dependency or cross-context
  contract was introduced.
- Portal remains Buyer-only. `BOM` remains `OPEN`/`DEFERRED` because no accepted
  role, endpoint, entity or lifecycle contract exists.
- Mock adapters remain isolated test fixtures and are not selected by browser
  runtime configuration.

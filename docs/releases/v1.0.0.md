# Nexa Buyer Portal v1.0.0

## Summary

V1 functional convergence baseline for the Buyer Portal.

## Included baseline

- Current Buyer availability, Purchase Request and delivery continuation surfaces.
- Consolidated Angular 22 dependency baseline with TypeScript 6 compatibility.
- Buyer-safe data boundaries, localized operations and runtime validation.

## Boundary

Documents, uploads and payments are not implemented in the Buyer Portal by this release.

## Validation

- Catalog asset validation passed.
- Tests, production build and CI gates passed.

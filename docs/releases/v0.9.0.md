# Nexa Buyer Portal v0.9.0

## Historical version mapping

Former historical label: `v0.11.0`. Public version: `v0.9.0`. Target commit,
original chronology and release evidence were preserved during the
Owner-authorized SCM normalization on 2026-09-01.

## Summary

PRE-V1 Architecture & Governance Foundation milestone for the Nexa Buyer Portal.

## Included baseline

- Four-step Purchase Request ordering experience (`Items -> Delivery & Terms -> Commercial Review -> Submission Confirmation`).
- Canonical Purchase Request Draft server API integration.
- Buyer domain model boundary cleanup (removing warehouse internals).
- Neutralized buyer delivery tracking.
- Nexa Design Lab v1.0.1 design token integration and responsive/accessibility enhancements.

## Boundary

Documents, uploads and payments are not implemented in the Buyer Portal by this release. This milestone does not represent Nexa V1 functional completion or Production Readiness.

## Validation

- 90 unit tests passed across 44 test suites.
- Angular production build passed.
- Portal CI gates passed.
